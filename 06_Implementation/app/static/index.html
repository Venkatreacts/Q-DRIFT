      Results
      
      
      All 81 NASA channels, streamed in time order. Event-level scoring follows the benchmark's own protocol (Hundman et al., KDD 2018): an anomaly counts as found if any alarm overlaps it, and an alarm that overlaps no anomaly is a false alarm.

      Encoding library
      
      
      Eighteen ways to load a telemetry window into six qubits: three circuit families, three bandwidths, two depths. Expressibility is the KL divergence from Haar-random states (lower means more expressive); entangling capability is the mean Meyer–Wallach measure.
      
      
      
      
      
    
      

    
    
      
      
      Kernel lab
      
      
      A quantum kernel is the overlap between two encoded states. Each heatmap compares 60 normal windows with 60 windows from labelled anomalies; a useful kernel shows a bright normal block and a dim cross block.
      
      
      
        
      Kernel matrix
      
          
          
      
        
      Kernel concentration
      
          
          
      Variance of off-diagonal kernel values against qubit count (log scale), on real telemetry windows. Too wide a bandwidth (β = 1) collapses exponentially as qubits are added; too narrow (β = 0.1) makes every window look alike. Only the band in between gives the detector something to work with, which is why Q-DRIFT searches bandwidth, not only circuit type.
      
      
      
    
      

    
    
      
      
      NASA SMAP and MSL telemetry
      
      
      Expert-labelled telemetry from the SMAP soil-moisture satellite and the Curiosity rover (Hundman et al., KDD 2018). Each tile is one channel's test stream with its labelled anomalies in red. Select a tile to replay it.
      
      
      
      
      
    
      

    
    
      
      
      How Q-DRIFT works
      
      
      One loop runs for every new telemetry window. The quantum model is small and cheap to refit; the expensive part, choosing an encoding, happens only when the data's behaviour actually changes.

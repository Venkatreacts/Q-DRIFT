# Q-DRIFT console

Drift-aware quantum kernel anomaly detection on the NASA SMAP/MSL telemetry benchmark: mission replays, live runs of the engine with injected drift, results on all 81 channels, the 18-encoding library and the kernel lab.

Quantum circuits are simulated with PennyLane on CPU. Data: NASA JPL SMAP/MSL anomaly benchmark (Hundman et al., KDD 2018).

LLJ II project, Quantum Machine Learning, SRM Institute of Science and Technology.
